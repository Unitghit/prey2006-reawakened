A small update to 1.0.0.

## Changes

- **Xbox controllers work out of the box.** 1.0.0 detected controllers but shipped without any controller bindings. A default layout is now applied when none are set: left stick to move, right stick to look, triggers to attack, A to jump, B to crouch, X for the lighter, Y for spirit walk, bumpers to switch weapons and the D-pad for weapon slots 1–4. If you have bound any controller buttons yourself, your bindings are kept.
- **Fixed portals that could no longer be placed** after a dead enemy fell partly through a floor portal. The body is now lifted out of the opening and the new portal goes in.
- **New option: No fall damage.** In the launcher under Gameplay. Single-player only, off by default.

## Updating

Extract `Prey2006-Reawakened-1.0.1-win64.zip` over your existing folder and replace files when asked. Your saves, settings and imported game data are kept. New installs: see the [README](https://github.com/Unitghit/prey2006-reawakened#installing).

## Files

- `Prey2006-Reawakened-1.0.1-win64.zip`: the game
- `Prey2006-Reawakened-1.0.1-source.zip`: source code for this release
- `SHA256SUMS.txt`: checksums for both
