First public release of Prey2006 Reawakened, a remaster of Prey (2006) for modern Windows PCs built on the [Prey2006](https://github.com/FriskTheFallenHuman/Prey2006) source port, with fixes adapted from [openPREY](https://github.com/themuffinator/openPREY).

You need your own copy of Prey (2006) for PC (Steam, GOG or disc). No game files are included.

## What's new

- Unlocked frame rate with smooth camera, weapons, vehicles and portal crossings
- Corrected lighting, specular and bloom
- Longer portal draw distance and portals inside portals, up to six deep
- Optional dynamic shadows for the flashlight and muzzle flashes
- A portal gun that works on Prey's walls, floors and ceilings (press 1 again to switch from the wrench)
- Optional Doom 3 weapons, converted from your own copy of Doom 3
- Movement styles from Quake, Painkiller, Half-Life and Half-Life 2
- Xbox controller support, English translation of alien screens, Cherokee difficulty unlocked
- A launcher that finds your games and sets everything up
- Fixes for crashes, stuck spots, and a long list of portal and rendering glitches

The full list is in the [changelog](https://github.com/Unitghit/prey2006-reawakened/blob/main/CHANGELOG.md).

## Installing

1. Download `Prey2006-Reawakened-1.0.0-win64.zip` below and extract it somewhere you can save files, like `C:\Games` (not Program Files).
2. Run `Prey2006 Reawakened Launcher.exe` and follow Setup.
3. Pick your settings and hit Save & Play.

Saves and settings stay in the `userdata` folder. Windows 10/11 64-bit only for now; Linux and Proton haven't been tested. See [known issues](https://github.com/Unitghit/prey2006-reawakened/blob/main/docs/release/KNOWN-ISSUES.txt).

## Files

- `Prey2006-Reawakened-1.0.0-win64.zip`: the game
- `Prey2006-Reawakened-1.0.0-source.zip`: source code for this release
